# CodeAlpha Data Visualization

## Task 3: Data Visualization

This project is created as part of the CodeAlpha Data Analytics Internship.

## Objective

The objective of this project is to transform book data into meaningful visualizations and identify useful patterns and trends.

## Dataset

The dataset contains information about books collected from a public website.

The main attributes are:

- Book Title
- Price
- Availability
- Rating

## Data Visualization Process

The following steps were performed:

1. Loaded the book dataset using Pandas.
2. Converted book prices into numeric values.
3. Analyzed book prices and ratings.
4. Created different charts using Matplotlib.
5. Used visualizations to understand patterns and compare book information.

## Visualizations

### 1. Price Distribution

Shows how book prices are distributed across different price ranges.

### 2. Rating-wise Number of Books

Shows the number of books available for each rating.

### 3. Top 10 Most Expensive Books

Shows the ten books with the highest prices.

### 4. Book Price vs Rating

Shows the relationship between book price and rating.

## Technologies Used

- Python
- Pandas
- Matplotlib

## Files

- `data_visualization.py` - Python code for creating visualizations
- `books_dataset.csv` - Book dataset
- `visual_price_distribution.png` - Price distribution graph
- `visual_rating_distribution.png` - Rating distribution graph
- `top_10_expensive_books.png` - Top 10 expensive books graph
- `visual_price_vs_rating.png` - Price versus rating graph

## Conclusion

The visualizations provide a clear understanding of book prices and ratings. Data visualization makes it easier to identify patterns, compare values and communicate insights from the dataset.
